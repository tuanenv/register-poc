Validation Rules

กติกาเวอร์ชัน POC สำหรับไฟล์รายชื่อแขก

  • ต้องมีหัวตารางครบ 27 คอลัมน์ตาม Template
  • ลำดับต้องเป็นตัวเลขและห้ามซ้ำ
  • เบอร์โทรเก็บเป็นข้อความเพื่อรักษาเลข 0 ด้านหน้า
  • ค่า “-” และช่องว่างจะแปลงเป็น null
  • Unique Key ที่มีค่าห้ามซ้ำภายในไฟล์เดียวกัน
  • วันที่ Excel Serial หรือข้อความวันที่จะแปลงเป็น ISO Date
  • สถานะลงทะเบียนต้องเป็น ลงทะเบียนแล้ว/ยังไม่ลงทะเบียน
  • ข้อมูล Error จะไม่รวมในชุด JSON ที่พร้อมนำเข้า
